# HooSharper review — October 7, 2026

## Scope

Three agents reviewed all 20 analyzer/code-fix/test pairs in parallel, then
reviewed one another's changes. The coordinating agent reviewed integration,
benchmark correctness, package contents, and real SDK consumers. All findings
below were fixed without changing diagnostic IDs or default severities.

## Older formatter limitation

An additional isolated run changed only the test host to Roslyn 4.8 and built
successfully with zero warnings/errors. It passed 449 of 451 tests. The two exact
text failures are `PreservesBlockCommentAfterClosingBrace` and
`PreservesCommentsAttachedToBraceTokens`: Roslyn 4.8 indents the retained trailing
comments by 12 spaces where Roslyn 5.9 uses 8. Comments remain present and ordered,
and the resulting source compiles. The new semantic regressions pass in both
hosts. This run confirms functional API compatibility; formatting is not
byte-identical across host versions. No interactive IDE session was tested.

## Reproduce

```sh
dotnet restore HooSharper.slnx
dotnet build HooSharper.slnx -c Release --no-restore
dotnet test tests/HooSharper.Analyzers.Tests/HooSharper.Analyzers.Tests.csproj \
  -c Release --no-build --collect:"XPlat Code Coverage" \
  --results-directory TestResults/review -- \
  DataCollectionRunSettings.DataCollectors.DataCollector.Configuration.Format=cobertura
dotnet run --project benchmarks/HooSharper.Performance/HooSharper.Performance.csproj \
  -c Release --no-build -- --validate-fixtures
dotnet pack src/HooSharper.Analyzers/HooSharper.Analyzers.csproj \
  -c Release --no-build -o artifacts
python3 scripts/verify-package.py artifacts/HooSharper.Analyzers.*.nupkg
python3 scripts/verify-consumer.py artifacts/HooSharper.Analyzers.*.nupkg
python3 scripts/verify-consumer.py artifacts/HooSharper.Analyzers.*.nupkg \
  --framework net8.0 --sdk-version 8.0.100
bun run check-readme-version
```

The consumer commands require the selected SDKs installed. The normal release
workflow owns version/changelog changes and NuGet publication; this review does
not publish the locally built package.
