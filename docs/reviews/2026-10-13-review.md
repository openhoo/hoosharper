Native reports include hints and explicitly enable redundant braces and
ThrowIfNull. Roslyn analyzer findings within ReSharper reports are excluded from
native totals. Seventeen HOO rules have native inspection mappings. HOO1010,
HOO1016 and HOO1020 have no matching native inspection in the captured catalog.

Mappings describe opportunities, with inclusive line overlap; they are not
one-to-one transformation equivalence. InvertIf is shared by HOO1001/HOO1004;
MergeConditionalExpression covers HOO1014/HOO1015 and additional native shapes.
The raw findings and unmatched rows remain available for source review.

Source review closed safe nullable HasValue, simple declaration-pattern, and
compound termination gaps. Other sampled differences follow existing scope:

- Native brace removal covers loops/locks; HOO1002 covers if branches.
- Native InvertIf covers nonvoid and nested guards; HOO1001/HOO1004 have narrower
  final method/immediate loop scope.
- Native conditional return conversion covers arbitrary values and throwing
  branches; HOO1017 covers opposite boolean literals.
- Native redundant-else removal includes `else if` chains; HOO1003 preserves
  those chains. For example, Dapper's `GetValue<T>` and Newtonsoft.Json's BSON
  state branches account for sampled unmatched native hints.
- Property null assignments may invoke getters/setters; HOO1008 requires stable
  locals, parameters or fields.
- Native conditional merging includes nullable casts, non-null fallback values,
  and type-test/as transformations beyond HOO1014/HOO1015.
- Chained or nonfinal using statements may change disposal scope; HOO1013 skips
  them.
- Dictionary factory values, comparer-sensitive expressions, writes and inactive
  preprocessor branches explain skipped collection shapes.

This campaign validates inspections plus HooSharper code-action/Fix All behavior.
It does not exercise interactive Rider/ReSharper quick-fix UI, run every original
framework target, or run third-party test suites against rewritten library code.
Library compilation and nullable warnings provide smoke evidence; the executable
matrix and targeted runtime probes provide behavior evidence.
